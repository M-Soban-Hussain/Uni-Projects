University Projects by M. Soban Hussain
1. 2D Retro Arcade Fighting Game

This project is a 2D fighting game built with SFML, featuring animated characters with states like Idle, Move, Jump, Punch, and Kick. It includes player controls, basic enemy AI, gravity simulation, and collision detection for health management.

Current version consolidates all game logic into a single file for simplicity. Planned improvements include modular code structure, multiplayer support, sound effects, and multiple characters to enhance gameplay.

Developed as a 2nd semester project for CS-114 at NUST CEME.

2. CSA Complex Engineering Problem (CEP)

This project is the design and implementation of a single-cycle RISC-V processor with an integrated multicycle hardware multiplier. It supports standard RISC-V instructions and handles multiplication/division over multiple cycles without affecting the main datapath.

Key components include the instruction memory, ALU, control unit, register file, data memory, branching logic, and the multicycle multiplier co-processor.

Developed as a 3rd semester project for EC-220 at NUST CEME, focusing on modular SystemVerilog design, simulation, and hardware integration.
