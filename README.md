## **2D Retro Arcade Fighting Game** 🎮

This is a **2D fighting game** built with **SFML**, featuring animated characters with states like *Idle*, *Move*, *Jump*, *Punch*, and *Kick*. It includes:

* **Player controls**
* **Basic enemy AI**
* **Gravity simulation**
* **Collision detection** for health management

The **current version** consolidates all game logic into a **single file** for simplicity. Planned improvements include:

* **Modular code structure**
* **Multiplayer support**
* **Sound effects**
* **Multiple playable characters**

*Developed as a 2nd semester project for CS-114 at NUST CEME.*

## **CSA Complex Engineering Problem (CEP)** 🖥️

This project involves the design of a **single-cycle RISC-V processor** with an integrated **multicycle hardware multiplier**. Key features include:

* **Standard RISC-V instruction support**: arithmetic, logical, memory access, and control-flow
* **Multicycle multiplier** for efficient multiplication/division without slowing the main datapath
* **Modular design** with SystemVerilog modules: *ALU, Control Unit, Register File, Instruction & Data Memory, Branching Logic*

*Developed as a 3rd semester project for EC-220 at NUST CEME*, focusing on:

* **Hardware integration**
* **Simulation and verification**
* **Clear modular structure for learning and FPGA implementation**
